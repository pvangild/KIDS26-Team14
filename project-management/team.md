# Team and Roles

- **Team name:** Team 14 - Multimodal Sleep Disordered Breathing Event Classificiation
- **Team lead:** Lu Xie (Github ID: lxie3)
- **Communication channel:** [Add link]
- **Project question/problem:** This project aimed to develop a machine-learning workflow to detect sleep disordered breathing events in pediatric polysomnography data and estimate the clinical Apnea-Hypoapnea Index (AHI). 
- **Expected output:** A model that detects and localizes apnea and hypoapnea events, determines apnea severity using AHI guidelines, and generates visualizations of underlying events.
- **Tools and stack:** Python, Matplotlib, Github Copilot, Github Repository, VS code
